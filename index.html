پشتیبان‌گیری و بازیابی

خروجی JSON دریافت فایل پشتیبان کامل از تمام داده‌های پنل
خروجی صفحه عمومی HTML ساخت فایل آماده برای آپلود روی هاست
بازیابی از فایل JSON فایل پشتیبان را بکشید و رها کنید یا کلیک کنید

همگام‌سازی با سایت اصلی

منبع داده (ACTIVITY_API_URL) آدرس قابل تنظیم برای دریافت اطلاعات فعالیت ادمین‌ها
وضعیت آخرین همگام‌سازی هنوز اجرا نشده است
نکته مهم: در حالت فعلی، اگر منبع مورد نظر فقط HTML باشد یا CORS اجازه ندهد، همگام‌سازی موفق نخواهد شد. یک لایه Adapter آماده شده تا با اتصال یک Backend Proxy یا API واقعی، به‌صورت خودکار فعال شود. اطلاعات ساختگی نمایش داده نمی‌شود.

Developer Notes

معماری Permission: کل منطق دسترسی در PERMISSIONS_BY_RANK و توابع hasPerm() / canCreateRank() / canActOnRank() متمرکز شده است؛ هیچ Rank-check پراکنده‌ای در Eventها وجود ندارد.
Activity Tracker: منبع داده از ACTIVITY_API_URL (بالا) خوانده می‌شود. در صورتی که مرورگر به دلیل CORS نتواند مستقیماً به log.slvcollective.ir متصل شود، پنل به‌جای داده جعلی پیام «Activity source unavailable» نمایش می‌دهد؛ آدرس Provider در همین صفحه قابل تغییر است تا بعداً به یک Proxy/Backend واقعی وصل شود.
آماده Backend: تمام عملیات حساس (createUser, changeRank, deleteUser, disableUser) از یک نقطه مرکزی عبور می‌کنند و برای اتصال به API واقعی در آینده نیاز به تغییر ساختار Frontend نیست.
